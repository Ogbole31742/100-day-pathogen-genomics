# 100-Day Healthcare Pathogen Genomics Challenge

## Project Title

From Raw Genomic Data to Antimicrobial Resistance Surveillance and Public-Health Intelligence

## Primary Pathogen

Klebsiella pneumoniae

## Secondary Pathogen

Escherichia coli

## Healthcare Problem

Antimicrobial resistance in healthcare-associated bacterial pathogens.

## Project Goal

To develop practical skills in pathogen genomics and bioinformatics by analyzing publicly available bacterial genomic data and investigating antimicrobial resistance, virulence, plasmids, pangenomics, phylogenomics, and genomic surveillance.

## Core Workflow

Raw sequencing data
→ Quality control
→ Preprocessing
→ Genome assembly
→ Genome annotation
→ AMR analysis
→ Virulence analysis
→ Plasmid analysis
→ Pangenomics
→ Phylogenomics
→ Epidemiological integration
→ Genomic surveillance
